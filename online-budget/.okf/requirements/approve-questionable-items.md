# Approve Questionable Items

## Description
As a user, I want to review and approve transactions that couldn't be auto-categorized so my records stay accurate.

## Acceptance Criteria
1. Pending transactions are shown in a review queue
2. User can assign a category from available options
3. Approval reinforces the matching rule for future auto-categorization
4. Review queue is accessible from the dashboard

## Priority
high

## Stakeholder
End user
