§ 00

Layering rules — read before writing code

10 rules

The codebase follows strict clean-architecture layering. Dependencies flow one direction only:

delivery mechanisms (views, jobs, commands)
        ↓ build DTO, call one usecase
application (use cases)
        ↓ call
services (core/domain)
        ↓ call
repositories, factories, handlers
        ↓ hydrate / create
models (domain entities)

Hard rules — violate these and the build is wrong:

  1. One use case per request. A view or job builds exactly one DTO and calls exactly one usecase.execute(dto). Never two.
  2. Views never touch repositories. Views call use cases only.
  3. Use cases never import Django. They take ports (ABCs) as constructor args. Django lives only in infrastructure/.
  4. Repositories return domain entities, never ORM models. Hydrate via Entity.fromDatabase(row).
  5. Handlers are pure functions, constructed with plain vars, never DI-registered. For v1, ExactMatcher / TitleNormalizer are handlers called by CategorizationService.
  6. DTOs are data only. No methods. Built by the delivery mechanism, passed to usecase.execute(dto).
  7. Presenters never call services/repositories. They take use-case output, build a ViewModel, pick a Component.
  8. Templates read vm.* only. No computation, no formatting in templates.
  9. AUTO_APPROVE_THRESHOLD is a class attribute on AutoCategorizeUseCase, not a Django setting.
  10. Credentials never committed, never logged. .env only, gitignored.

§ 11 · S8

Infrastructure: RBC scraper + CSV parser

2–3 days

infrastructure/rbc/selectors.py — all RBC CSS selectors centralized here. When RBC changes its UI, one file is patched.

infrastructure/rbc/scraper.py — PlaywrightRBCScraper implementing RBCScraper. Creds from env (RBC_USERNAME, RBC_PASSWORD) — never logged. Flow: login → accounts → joint chequing → export → CSV → download → parse. Explicit timeouts (wait_for_selector(..., timeout=15000)), no implicit waits. MFA prompt → raise RBCLoginError (first login must be manual). Failure → raise SyncFailed.

infrastructure/rbc/csv_parser.py — parse_csv(path) -> list[dict]. Validates EXPECTED_HEADERS against the export; raises SyncFailed if schema changed. Derives rbc_transaction_id from date+description+amount (dedup key). Normalizes date from MM/DD/YYYY to ISO.

Note

EXPECTED_HEADERS and date format assumption must be confirmed against a real RBC export — see Exceptions.

Exceptions

Flagged in red pencil — resolve before the matcher ships

  • Normalization samples missing. Pull 30–50 real RBC transaction descriptions into samples/rbc_descriptions.txt. RBC embeds store numbers / ref codes / dates in descriptions (TIM HORTONS #4521 vs #0192) — the normalization rule must be locked against real samples before the matcher is built. Until then, TitleNormalizer returns identity (raw string match).
  • CSV parser schema assumed. EXPECTED_HEADERS and date format (MM/DD/YYYY) are assumptions — confirm against a real RBC export before relying on them. If the export uses different column names, update csv_parser.py and its test.
  • RBC selectors unverified. The selectors in selectors.py are placeholders — the implementer must inspect the real RBC online banking DOM (via Playwright headed mode) and patch the file. This is expected; the scraper is designed so this is the only file to touch.

Footnotes — risk register

  1. 01RBC login UI breaks. Selectors in one file; Playwright downloads CSV not DOM-scrapes; alert on SyncFailed.
  2. 02RBC changes CSV format. csv_parser.py schema-validated; fail loudly with SyncFailed, not silently.
  3. 03RBC blocks headless automation. Spoof user-agent, disable AutomationControlled. If persistent, fall back to manual CSV upload endpoint (out of v1 scope).
  4. 04ORM broker lost job on crash. Django-Q2 ORM broker persists to DB; retry=120 requeues. Acceptable for a 2-person tool.
  5. 05Pi SD card corruption. USB SSD boot only; daily pg_dump + rclone.
  6. 06Spouse can't reach Pi when traveling. Tailscale on phones; Tailscale Funnel if public HTTPS is ever needed.
  7. 07Credential leak. .env only, gitignored; django-environ; never logged; Pi filesystem encryption optional.
  8. 08Exact match under-matches. times_confirmed counter + manual approve reinforces rules over time. Revisit fuzzy matching only if hit rate <60% after 3 months.
